# Проверка Just Organize Yourself

Дата начала: 2026-11-08. Роль: независимый критик и тестировщик.

## Правила приёмки

Функция считается проверенной после выполнения сценария с фактическим результатом. Наличие класса, кнопки, файла или успешной сборки само по себе не подтверждает пользовательский сценарий. Проверки авторов дополняются независимыми проверками критика.

Приоритеты: сохранность данных, самостоятельная работа Android-клиента, понятный интерфейс, соответствие ТЗ. Не добавлять поведение других продуктов. Экспорт Calendar направлен только из приложения; обратный импорт не согласован. Опциональные вычисления не должны блокировать основной GTD-сценарий.

## Дефекты, найденные при проверке и исправленные

- Add-импорт мог обходить проверку версии схемы и схлопывать одинаковые ID до валидации. Добавлена предварительная проверка; ошибки не меняют текущую систему.
- Некорректные даты могли нормализоваться парсером, а незаполненный проект — пройти через импорт. Валидация перенесена и на границу данных.
- XLSX собственный экспорт/импорт расходился по строке заголовка служебного листа. Реальный round-trip теперь проходит, включая длинные Unicode-поля и большие массивы векторов.
- Первый настоящий peer commit отклонялся из-за разных способов вычисления state token. Канонизация унифицирована; loopback exchange и повтор проходят.
- Удаление папки на одном устройстве при независимом дочернем добавлении на другом предлагало неприменимую версию. Зависимые записи показываются, небезопасный вариант блокируется; незаметного каскадного удаления нет.
- Replace из старого XLSX мог вернуть удалённые задачи при следующем обмене либо потерять осознанное восстановление старой версии. Импорт стал явным изменением с tombstones и ancestry; неизвестные правки второго устройства остаются конфликтами. Отмена восстанавливает прежний снимок.
- Нулевой вектор ошибочно принимался как результат модели. `/v1/embed` теперь отвергает непригодные результаты; отсутствие модели остаётся честным `503`.
- Выходной ICS мог повреждать кириллицу из-за UTF-16 code units вместо UTF-8. Байтовая запись исправлена.
- Папка в Trash оставалась в навигации. Активная навигация отфильтрована.
- Модальные формы переполняли экран с клавиатурой и освобождали `TextEditingController` до завершения обратной анимации. Формы прокручиваются; контроллеры живут до полного закрытия route.
- Enter на компьютере не отправлял запись, а смена размеров при открытии клавиатуры могла сбрасывать composer. Добавлены явное действие Enter и стабильная идентичность виджета.
- Длинные русские/немецкие подписи переполняли AppBar; nav ListTile не имел корректного Material-фона. Узкая компоновка и материал исправлены.
- Пан-жест карточки проигрывал прокрутке страницы. Исправлено владение жестом только на области карточки; все восемь настоящих drag-сценариев проходят, как и тап с редактированием.
- Native Linux запуск обнаружил конфликт системной и bundled SQLite, не воспроизводившийся в unit/widget-тестах. Приоритет bundled библиотеки исправлен; создание SQLite и seed-данных при native запуске подтверждено отдельно.

## Ограничения проверки

- Android SDK установлен, debug APK собран. Физический телефон и Android-эмулятор в приёмке не использовались. Сборка APK и widget-тест не заменяют испытание реальных жестов, разрешений, file picker и локальной сети на устройстве.
- Доступ к Google Calendar не запрошен: сначала проверяется корректность экспортируемого формата. Реальный импорт файла пользователем в Google Calendar отмечается отдельно, если выполнен.
- Реальная модель и сквозной путь Flutter → Python → SQLite → XLSX проверены. Заглушки использовались только для намеренной инъекции ошибок. Метрики памяти и задержки зависят от целевого компьютера; измеренное качество одного примера не является гарантией для всех записей.
- Домашний Wi-Fi и телефонная точка доступа не объявляются проверенными по результату loopback-теста двух процессов.
- Локальная синхронизация сейчас использует показанный адрес устройства и код. Автоматическое обнаружение, QR и TLS-транспорт не реализованы; это не скрывается под успешным loopback-тестом.
- Native первый экран просмотрен после запуска в Xvfb с программным рендерингом и необходимыми библиотеками пользовательского префикса. Все системные диалоги и платформенные способы ввода на обычном пользовательском desktop ещё не испытаны. Widget-снимки со стандартным тестовым Ahem-шрифтом не использованы как доказательство качества реальных шрифтов.
- iOS отложен по поручению владельца; сборки и проверки iOS не заявляются. Windows/macOS на этой Linux-машине не проверены.

## Несогласованные предложения

Вне согласованной области новые возможности не добавлялись. UUID, ancestry, служебные строки XLSX, номера записей, безопасное закрытие форм и блокировка небезопасного выбора — технические детали уже запрошенных сценариев.

Обратная загрузка Google Calendar, предиктивная сортировка, покупки из Shopping Lists и сторонняя автоматизация не реализованы. Вопросы о дальнейшем развитии не блокируют текущие автономные capture/organize/backup/merge-сценарии.
