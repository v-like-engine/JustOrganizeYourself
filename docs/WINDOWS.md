# Windows: скачать и запустить

Для обычного использования не нужны Flutter, Visual Studio, Python, Java или отдельная установка SQLite. Приложение и необходимые библиотеки входят в готовый пакет.

Поддерживается Windows 10 версии 2004 и новее или Windows 11, 64-битная x64-система.

## Вариант 1 — установщик

1. Откройте [Windows preview](https://github.com/v-like-engine/JustOrganizeYourself/releases/tag/v0.1.0-windows-preview.1).
2. Скачайте **JOY-Windows-Setup.exe** и откройте его.
3. Завершите установку и запустите **Just Organize Yourself** из меню «Пуск» или с рабочего стола.

Программа устанавливается в папку вашего пользователя, без требования прав администратора. Установщик работает без скачивания дополнительных компонентов. В конце установки можно сразу открыть приложение.

## Вариант 2 — без установки

На той же странице скачайте **JOY-Windows-Portable.zip**, распакуйте его целиком и откройте **JustOrganizeYourself.exe** в распакованной папке. Файлы DLL и папку `data` оставьте рядом с `.exe`; в архив уже включены все необходимые компоненты.

Здесь «без установки» относится к программе: данные хранятся в вашем профиле Windows, поэтому перемещение или обновление папки приложения не удаляет задачи. Для переноса самого GTD-хранилища на другой компьютер используйте экспорт XLSX.

## Данные и обновления

- База находится в `%APPDATA%\dev.justorganize\joy\joy.sqlite`.
- Перед обновлением закройте приложение. Новую версию можно установить поверх старой или распаковать в отдельную папку.
- Удаление программы не удаляет базу задач в профиле пользователя.
- Для резервной копии используйте **Import & export → Export all to XLSX** внутри приложения.
- При первом запуске интерфейс английский; русский выбирается в **Settings → Language**.

Это предварительная версия без сертификата подписи издателя. Windows может показать предупреждение SmartScreen о неизвестном приложении. Готовые файлы следует брать со страницы релиза этого репозитория; `SHA256SUMS.txt` содержит их контрольные суммы.

Семантические эмбеддинги — отдельная необязательная возможность. Для Inbox, папок, проектов, XLSX, календарного экспорта и локальной синхронизации Python-сервис не требуется.

## Как проверяется пакет

Сборка выполняется на Windows-машине GitHub Actions. Процесс собирает release-версию, добавляет app-local Microsoft C++ runtime, создаёт ZIP и установщик и проверяет:

- запуск `.exe` с `PATH`, содержащим только системные папки Windows;
- загрузку Flutter, SQLite и C++ runtime из папки приложения;
- появление окна и создание корректного файла SQLite;
- установку, запуск установленной копии и удаление программы;
- неизменность файлов базы и WAL после удаления программы;
- core- и Flutter-тесты на Windows.

Ссылка на конкретный выполненный прогон и фактические результаты сохраняются в релизе и отчёте проверки. Windows-сборка не заменяет проверки на физическом Android или macOS.

## Для разработчиков

Настройка Flutter и Visual Studio нужна только тем, кто меняет или самостоятельно собирает исходники. Автоматизация находится в [.github/workflows/windows.yml](../.github/workflows/windows.yml); пакет создаёт [package.ps1](../scripts/windows/package.ps1), установщик описан в [installer.iss](../packaging/windows/installer.iss).
